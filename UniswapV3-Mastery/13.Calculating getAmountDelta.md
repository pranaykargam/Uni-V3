
# Uniswap V3 — `getAmountDelta`

## 1. What Is New?

The library implements the real-reserve formulas using **Q64.96 square-root prices**, rather than ordinary prices.

$$
\boxed{\sqrt{P}=\frac{\text{sqrtPriceX96}}{2^{96}}}
$$

## 2. Core Implementation Formulas

**Token 0 — `getAmount0Delta`**

$$
\boxed{
\text{amount0}=
\frac{L\cdot 2^{96}\cdot(B-A)}{A\cdot B}
}
$$

**Token 1 — `getAmount1Delta`**

$$
\boxed{
\text{amount1}=
\frac{L\cdot(B-A)}{2^{96}}
}
$$

Where:

- `A` = lower square-root price in Q64.96
- `B` = upper square-root price in Q64.96
- `L` = liquidity

**Memory trick:** Token 0 divides by **both prices**; Token 1 divides by **\(2^{96}\)**.

## 3. Rounding — Important for Audits

| Situation | Rounding |
|---|---|
| Tokens deposited into the pool | Round up |
| Tokens paid out by the pool | Round down |

The code uses `mulDiv`, `mulDivRoundingUp`, and `divRoundingUp` where appropriate to handle integer arithmetic and rounding.

**Audit clue:** Check whether rounding favors the protocol or the user, especially when amounts are very small.

## 4. Important Limitation

These functions assume **constant liquidity over the supplied price interval**. They calculate token amounts for that interval; they do not discover how liquidity is distributed across the entire pool.

They are used in liquidity operations and swaps to calculate token amounts between prices.
