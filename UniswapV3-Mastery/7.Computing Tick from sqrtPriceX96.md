# Uniswap V3: `sqrtPriceX96` ↔ Tick

> **Short note:** Uniswap V3 stores the current **square-root price** as `sqrtPriceX96`.  
> A tick is a discrete price index. To get the tick, recover the price, take its logarithm, and round down.  
> Source: [RareSkills](https://rareskills.io/post/uniswap-v3-price-to-tick#changing-the-base-of-the-logarithm)


## Core Functions

Uniswap V3 uses two main `TickMath` functions to convert between tick and price.

### 1. `getSqrtRatioAtTick()`

Converts a **tick** into `sqrtPriceX96`.

```solidity
function getSqrtRatioAtTick(int24 tick)
    internal
    pure
    returns (uint160 sqrtPriceX96);
```

Relationship:

$$
\boxed{
\text{tick}
\rightarrow
\text{sqrtPriceX96}
}
$$

Formula:

$$
\boxed{
\text{sqrtPriceX96}
=
\sqrt{1.0001^{\text{tick}}}
\times 2^{96}
}
$$

Example:

```solidity
uint160 sqrtPriceX96 = TickMath.getSqrtRatioAtTick(0);
// sqrtPriceX96 = 2^96
```

### 2. `getTickAtSqrtRatio()`

Converts `sqrtPriceX96` back into a **tick**.

```solidity
function getTickAtSqrtRatio(uint160 sqrtPriceX96)
    internal
    pure
    returns (int24 tick);
```

Relationship:

$$
\boxed{
\text{sqrtPriceX96}
\rightarrow
\text{tick}
}
$$

Formula:

$$
\boxed{
\text{tick}
=
\left\lfloor
\log_{1.0001}
\left(
\left(
\frac{\text{sqrtPriceX96}}{2^{96}}
\right)^2
\right)
\right\rfloor
}
$$

Example:

```solidity
int24 tick = TickMath.getTickAtSqrtRatio(sqrtPriceX96);
```

### Relationship between both functions

```text
tick
 ↓ getSqrtRatioAtTick()
sqrtPriceX96
 ↓ getTickAtSqrtRatio()
tick
```

$$
\boxed{
\text{tick}
\rightarrow
\text{sqrtPriceX96}
\rightarrow
\text{tick}
}
$$

- `getSqrtRatioAtTick()` = **tick → square-root price**
- `getTickAtSqrtRatio()` = **square-root price → tick**
- They are inverse functions, with controlled rounding.

## 1. Tick price

A tick $i$ represents this price:

$$
\boxed{P(i) = 1.0001^i}
$$

One tick changes price by about **0.01%**.

## 2. `sqrtPriceX96` meaning

`sqrtPriceX96` is a Q64.96 fixed-point value.

$$
\boxed{\sqrt{P} = \frac{\text{sqrtPriceX96}}{2^{96}}}
$$

So the raw price is:

$$
\boxed{P = \left(\frac{\text{sqrtPriceX96}}{2^{96}}\right)^2}
$$

## 3. `sqrtPriceX96` → Tick

$$
\boxed{
i =
\left\lfloor
\frac{
2\log\left(\frac{\text{sqrtPriceX96}}{2^{96}}\right)
}{
\log(1.0001)
}
\right\rfloor
}
$$

The floor $\lfloor \cdot \rfloor$ is needed because price is continuous, but tick is an integer.

## 4. Tick → `sqrtPriceX96`

$$
\boxed{
\text{sqrtPriceX96}
=
\sqrt{1.0001^i} \times 2^{96}
}
$$

At tick `0`:

$$
\boxed{\text{sqrtPriceX96} = 2^{96}}
$$

## 5. Changing log base

The log base does **not** matter if both logs use the same base:

$$
\boxed{
\log_b(k)
=
\frac{\log_a(k)}{\log_a(b)}
}
$$

So both formulas give the same tick:

$$
\boxed{
i =
\left\lfloor
\frac{
2\ln\left(\frac{\text{sqrtPriceX96}}{2^{96}}\right)
}{
\ln(1.0001)
}
\right\rfloor
}
$$

$$
\boxed{
i =
\left\lfloor
\frac{
2\log_{10}\left(\frac{\text{sqrtPriceX96}}{2^{96}}\right)
}{
\log_{10}(1.0001)
}
\right\rfloor
}
$$

The base-conversion factor cancels out.

## 6. Simple workflow

```text
Read slot0.sqrtPriceX96
        ↓
Divide by 2^96
        ↓
Square the result → raw price P
        ↓
Take log(P) / log(1.0001)
        ↓
Round down → tick
```

Reverse workflow:

```text
Given tick i
        ↓
Calculate 1.0001^i
        ↓
Take square root
        ↓
Multiply by 2^96
        ↓
sqrtPriceX96
```

## 7. Audit checks

- `sqrtPriceX96` is **square-root price**, not price.
- Confirm token direction: raw price is `token1 / token0`.
- Apply token decimals before comparing with UI or fiat price.
- Tick conversion must round **down**.
- Check tick bounds:

$$
\boxed{-887272 \le i \le 887272}
$$

- Do not use `slot0.sqrtPriceX96` alone as a secure oracle; it is a spot price and can be manipulated during a transaction.

## Key takeaway

$$
\boxed{\text{tick} \leftrightarrow \text{discrete price index}}
$$

$$
\boxed{\text{sqrtPriceX96} \leftrightarrow \text{current square-root price}}
$$

$$
\boxed{P(i) = 1.0001^i}
$$
